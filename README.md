# Torcedor de Arquibancada

Site estático da loja (HTML + CSS + JS, sem build). Pedidos são finalizados pelo WhatsApp.

- **Configurar loja e catálogo:** `produtos.js` (WhatsApp, Instagram, preço da personalização, frete grátis, produtos).
- **Fotos:** coloque em `img/` e preencha o campo `imagem` do produto (ex.: `'img/flamengo.jpg'`). Sem foto, o site desenha a camisa com as cores do produto.
- **Publicar:** importar o repositório na Vercel (framework "Other", sem build command).
